Offline practice board

A fixed 9-row × 9-column board for learning the helper's setup. Left-click to uncover; right-click to flag. One flag and some revealed cells are already present. Nothing is sent over the network.

Select only the 9 × 9 tile grid, not its thick surrounding frame. Start by teaching C, F, 0, 1 and 2. Leave the browser zoom unchanged.

The helper's first provable, unflagged mine in this starting position is at row 3, column 3 (counting from 1). Use this to check alignment. The existing flag is a recognition example, not a solver instruction.
